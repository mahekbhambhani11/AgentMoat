Architecture & Live Demo
Elegantly simple under the hood.

guard.py

Core Engine

Computes L2 Euclidean distance from ChromaDB. Returns a float, not a binary — enabling per-endpoint threshold tuning.

database/ingest.py

Threat Intel

Parses JSONL threat datasets, embeds with all-MiniLM-L6-v2, seeds local ChromaDB. Add one row → instant global patch.

app.py

Control Plane

Streamlit dashboard: live slider calibration, real-time logs, OpenAI pass-through for cleared prompts.

🏆 The competitive moat: the threat signature dataset. The more signatures, the more accurate. Same network-effects dynamic as Snort rule libraries — but for LLM prompts.
